# دليل تفعيل نظام "المسؤول/الكاشير" — للشخص غير المبرمج

هذا الدليل يشرح **بالتفصيل وخطوة بخطوة** الأشياء المطلوبة منك أنت (وليس مني) حتى تشتغل ميزة فصل "المالك" عن "الكاشير" فعلياً في موقعك. لا يحتاج أي معرفة برمجية — فقط اتّباع الخطوات بالترتيب.

---

## أولاً: هل يحتاج الأمر أي شيء مني بالكود؟

**لا.** كل الكود جاهز ومرفوع فعلاً. الموقع (Vercel) يحدّث نفسه تلقائياً خلال دقائق قليلة من كل مرة أرفع فيها تعديلاً. أنت لا تحتاج تلمس أي كود إطلاقاً.

**الشيء الوحيد المطلوب منك** هو خطوة واحدة بموقع قاعدة البيانات (Supabase) — لأن هذه الخطوة لا يمكن لي تنفيذها بدلاً عنك تلقائياً (تحتاج حسابك أنت لتسجيل الدخول)، وهي: **إنشاء 4 "جداول" جديدة بقاعدة البيانات** (تخيّلها 4 دفاتر جديدة فارغة يُحفظ فيها: قائمة الموظفين، الورديات، طلبات الموافقة، وسجل من عمل ماذا). بدون هذه الخطوة، الميزة موجودة بالموقع لكنها لن تعمل (ستظهر أخطاء عند محاولة استخدامها).

---

## ثانياً: الخطوة المطلوبة — إنشاء الجداول (5 دقائق، مرة واحدة فقط)

### الخطوة 1 — افتح صفحة تحرير قاعدة البيانات

اضغط على هذا الرابط (يفتح لك محرر أوامر قاعدة البيانات الخاصة بمشروعك):

```
https://supabase.com/dashboard/project/gbmwrvnmvobvieembxmf/sql/new
```

إذا طلب منك تسجيل دخول، سجّل دخول بنفس الحساب اللي تدير فيه مشروعك على Supabase.

### الخطوة 2 — انسخ الكود التالي بالكامل

اضغط داخل الصندوق أدناه، اختر الكل (Ctrl+A أو من الجوال: اضغط مطوّلاً ثم "تحديد الكل")، وانسخ (Ctrl+C):

```sql
-- ============================================================
-- RBAC نظام صلاحيات الموظفين (المالك/المدير مقابل الكاشير)
-- ============================================================
CREATE TABLE IF NOT EXISTS restaurant_staff (
  id                    UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  restaurant_id         UUID        NOT NULL REFERENCES restaurants(id) ON DELETE CASCADE,
  display_name          TEXT        NOT NULL,
  role                  TEXT        NOT NULL CHECK (role IN ('owner', 'manager', 'cashier')),
  pin_hash              TEXT        NOT NULL,
  auth_user_id          UUID        REFERENCES auth.users(id) ON DELETE SET NULL,
  is_active             BOOLEAN     NOT NULL DEFAULT TRUE,
  max_discount_pct      NUMERIC(5,2)  NOT NULL DEFAULT 0,
  max_void_amount       NUMERIC(12,2) NOT NULL DEFAULT 0,
  failed_pin_attempts   INTEGER     NOT NULL DEFAULT 0,
  locked_until          TIMESTAMPTZ,
  push_subscription     JSONB,
  created_at            TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at            TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  CONSTRAINT restaurant_staff_discount_range CHECK (max_discount_pct >= 0 AND max_discount_pct <= 100),
  CONSTRAINT restaurant_staff_void_nonneg    CHECK (max_void_amount >= 0)
);

CREATE INDEX IF NOT EXISTS idx_staff_restaurant        ON restaurant_staff(restaurant_id);
CREATE INDEX IF NOT EXISTS idx_staff_restaurant_active ON restaurant_staff(restaurant_id, is_active);
CREATE INDEX IF NOT EXISTS idx_staff_auth_user         ON restaurant_staff(auth_user_id) WHERE auth_user_id IS NOT NULL;

CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

DROP TRIGGER IF EXISTS restaurant_staff_updated_at ON restaurant_staff;
CREATE TRIGGER restaurant_staff_updated_at
  BEFORE UPDATE ON restaurant_staff
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TABLE IF NOT EXISTS cashier_shifts (
  id                    UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  restaurant_id         UUID        NOT NULL REFERENCES restaurants(id) ON DELETE CASCADE,
  staff_id              UUID        NOT NULL REFERENCES restaurant_staff(id),
  opening_cash          NUMERIC(12,2) NOT NULL DEFAULT 0,
  expected_closing_cash NUMERIC(12,2),
  actual_closing_cash   NUMERIC(12,2),
  variance              NUMERIC(12,2),
  opened_at             TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  closed_at             TIMESTAMPTZ,
  status                TEXT        NOT NULL DEFAULT 'open' CHECK (status IN ('open', 'closed')),
  CONSTRAINT cashier_shifts_opening_nonneg CHECK (opening_cash >= 0)
);

CREATE INDEX IF NOT EXISTS idx_shifts_restaurant       ON cashier_shifts(restaurant_id);
CREATE INDEX IF NOT EXISTS idx_shifts_staff            ON cashier_shifts(staff_id);
CREATE INDEX IF NOT EXISTS idx_shifts_staff_open       ON cashier_shifts(staff_id) WHERE status = 'open';
CREATE INDEX IF NOT EXISTS idx_shifts_restaurant_status ON cashier_shifts(restaurant_id, status);

CREATE TABLE IF NOT EXISTS approval_requests (
  id              UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  restaurant_id   UUID        NOT NULL REFERENCES restaurants(id) ON DELETE CASCADE,
  requested_by    UUID        NOT NULL REFERENCES restaurant_staff(id),
  request_type    TEXT        NOT NULL CHECK (request_type IN ('void_order', 'refund', 'discount_override', 'price_override')),
  order_id        UUID        REFERENCES orders(id),
  amount          NUMERIC(12,2),
  reason          TEXT,
  status          TEXT        NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'approved', 'rejected')),
  resolved_by     UUID        REFERENCES restaurant_staff(id),
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  resolved_at     TIMESTAMPTZ
);

CREATE INDEX IF NOT EXISTS idx_approvals_restaurant        ON approval_requests(restaurant_id);
CREATE INDEX IF NOT EXISTS idx_approvals_restaurant_status ON approval_requests(restaurant_id, status);
CREATE INDEX IF NOT EXISTS idx_approvals_order             ON approval_requests(order_id) WHERE order_id IS NOT NULL;
CREATE INDEX IF NOT EXISTS idx_approvals_requested_by      ON approval_requests(requested_by);

CREATE TABLE IF NOT EXISTS staff_actions_log (
  id              UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  restaurant_id   UUID        NOT NULL REFERENCES restaurants(id) ON DELETE CASCADE,
  staff_id        UUID        REFERENCES restaurant_staff(id),
  action_type     TEXT        NOT NULL,
  entity_type     TEXT,
  entity_id       UUID,
  before_data     JSONB,
  after_data      JSONB,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_actions_log_restaurant      ON staff_actions_log(restaurant_id);
CREATE INDEX IF NOT EXISTS idx_actions_log_restaurant_time ON staff_actions_log(restaurant_id, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_actions_log_staff           ON staff_actions_log(staff_id);
CREATE INDEX IF NOT EXISTS idx_actions_log_entity          ON staff_actions_log(entity_type, entity_id);

CREATE OR REPLACE FUNCTION is_restaurant_owner(p_restaurant_id UUID)
RETURNS BOOLEAN AS $$
  SELECT EXISTS (
    SELECT 1 FROM restaurants
    WHERE id = p_restaurant_id
      AND owner_id = auth.uid()
  );
$$ LANGUAGE sql SECURITY DEFINER STABLE;

CREATE OR REPLACE FUNCTION is_super_admin()
RETURNS BOOLEAN AS $$
  SELECT COALESCE(
    (auth.jwt() -> 'user_metadata' ->> 'super_admin')::BOOLEAN,
    FALSE
  );
$$ LANGUAGE sql SECURITY DEFINER STABLE;

CREATE OR REPLACE FUNCTION get_staff_role(p_restaurant_id UUID)
RETURNS TEXT AS $$
  SELECT CASE
    WHEN EXISTS (SELECT 1 FROM restaurants WHERE id = p_restaurant_id AND owner_id = auth.uid())
      THEN 'owner'
    ELSE (
      SELECT role FROM restaurant_staff
      WHERE restaurant_id = p_restaurant_id AND auth_user_id = auth.uid() AND is_active = TRUE
      LIMIT 1
    )
  END;
$$ LANGUAGE sql SECURITY DEFINER STABLE;

ALTER TABLE restaurant_staff ENABLE ROW LEVEL SECURITY;
CREATE POLICY "restaurant_staff: owner can do all" ON restaurant_staff FOR ALL
  USING (is_restaurant_owner(restaurant_id)) WITH CHECK (is_restaurant_owner(restaurant_id));
CREATE POLICY "restaurant_staff: super_admin can do all" ON restaurant_staff FOR ALL
  USING (is_super_admin()) WITH CHECK (is_super_admin());

ALTER TABLE cashier_shifts ENABLE ROW LEVEL SECURITY;
CREATE POLICY "cashier_shifts: owner can do all" ON cashier_shifts FOR ALL
  USING (is_restaurant_owner(restaurant_id)) WITH CHECK (is_restaurant_owner(restaurant_id));
CREATE POLICY "cashier_shifts: super_admin can do all" ON cashier_shifts FOR ALL
  USING (is_super_admin()) WITH CHECK (is_super_admin());

ALTER TABLE approval_requests ENABLE ROW LEVEL SECURITY;
CREATE POLICY "approval_requests: owner can do all" ON approval_requests FOR ALL
  USING (is_restaurant_owner(restaurant_id)) WITH CHECK (is_restaurant_owner(restaurant_id));
CREATE POLICY "approval_requests: super_admin can do all" ON approval_requests FOR ALL
  USING (is_super_admin()) WITH CHECK (is_super_admin());

ALTER TABLE staff_actions_log ENABLE ROW LEVEL SECURITY;
CREATE POLICY "staff_actions_log: owner can do all" ON staff_actions_log FOR ALL
  USING (is_restaurant_owner(restaurant_id)) WITH CHECK (is_restaurant_owner(restaurant_id));
CREATE POLICY "staff_actions_log: super_admin can do all" ON staff_actions_log FOR ALL
  USING (is_super_admin()) WITH CHECK (is_super_admin());

ALTER TABLE stock_movements
  ADD COLUMN IF NOT EXISTS performed_by_staff_id UUID REFERENCES restaurant_staff(id) ON DELETE SET NULL;
CREATE INDEX IF NOT EXISTS idx_stock_mov_staff ON stock_movements(performed_by_staff_id)
  WHERE performed_by_staff_id IS NOT NULL;

ALTER TABLE orders
  ADD COLUMN IF NOT EXISTS pre_discount_total NUMERIC(12,2);
```

### الخطوة 3 — الصق الكود واضغط تشغيل

1. الصق الكود (Ctrl+V) داخل الصندوق الفارغ بصفحة Supabase.
2. اضغط الزر الأخضر **Run** (أو **▶ Run**) — عادة أسفل يمين الصفحة، أو اختصار `Ctrl+Enter`.
3. انتظر ثوانٍ قليلة. إذا ظهرت رسالة خضراء تقول **"Success"** أو **"Success. No rows returned"** — تم! الجداول انشأت بنجاح.

**ملاحظة:** الكود مصمم بحيث لا يخرّب أي شيء موجود عندك حالياً — فقط يُضيف أشياء جديدة. تقدر تشغّله بأمان.

⚠️ **إذا ظهر خطأ يذكر كلمة `stock_movements` غير موجودة**: هذا يعني أن نظام المخزون القديم لم يُفعَّل عندك بعد بقاعدة البيانات. أخبرني وسأعدّل الكود ليتوافق مع وضعك.

## ثالثاً: كيف تضيف أول كاشير (من الموقع نفسه، بدون أي كود)

بعد نجاح الخطوة أعلاه:

1. سجّل دخول لداشبورد المطعم كالعادة (نفس اسم المستخدم وكلمة المرور الحاليين — **لم يتغيّر شيء بدخولك أنت**).
2. اذهب إلى **الإعدادات**.
3. ستجد قسماً جديداً اسمه **"الموظفين"** — افتحه.
4. اضغط زر **+** لإضافة موظف جديد:
   - اكتب اسمه.
   - اختر دوره: **كاشير**.
   - حدّد رمز دخول (PIN) من 4 إلى 6 أرقام — هذا الرقم يستخدمه الكاشير للدخول لاحقاً (مثل رمز فتح الجوال).
   - حدّد "أقصى خصم بدون موافقة" و"أقصى مبلغ إلغاء بدون موافقة" — هذي حدود مالية تحميك من تلاعب الكاشير (أي شيء أكبر منها يحتاج موافقتك أنت فوراً).
5. اضغط **إضافة**. تم — الكاشير جاهز.

---

## رابعاً: كيف يدخل الكاشير

1. الكاشير يفتح نفس رابط الداشبورد بجهاز/تابلت المحل.
2. تظهر له شاشة **"من أنت؟"** — يضغط على اسمه من القائمة.
3. يدخل رمزه (PIN) الذي حدّدته له.
4. يدخل مباشرة لشاشة بيع مبسّطة (فتح وردية، طلبات، دفع) — **بدون أي رؤية للأرباح أو تكاليف المخزون أو الإعدادات**.

وأنت (المالك) تدخل بنفس طريقتك القديمة تماماً — تضغط على "المالك" بشاشة "من أنت؟" (أو تدخل مباشرة لو ما فيه موظفين مضافين بعد) وتشوف كل شيء كالمعتاد.
