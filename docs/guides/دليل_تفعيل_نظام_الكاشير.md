# دليل تفعيل نظام "المسؤول/الكاشير" — للشخص غير المبرمج

هذا الدليل يشرح **بالتفصيل وخطوة بخطوة** الأشياء المطلوبة منك أنت حتى تشتغل ميزة فصل "المالك" عن "الكاشير" فعلياً في موقعك. لا يحتاج أي معرفة برمجية.

> ⚠️ **تحديث:** آلية دخول الكاشير تغيّرت بالكامل عن نسخة سابقة من هذا الدليل — صار الكاشير يدخل بكود+كلمة مرور من صفحة تسجيل الدخول مباشرة، وليس بشاشة "من أنت؟" داخل الداشبورد. إذا كنت شغّلت الكود بقسم "ثانياً" سابقاً، لازم تشغّل الكود الجديد أدناه أيضاً (خطوة إضافية بسيطة، مرة واحدة).

---

## أولاً: هل يحتاج الأمر أي شيء مني بالكود؟

**لا.** كل الكود جاهز ومرفوع. الموقع (Vercel) يحدّث نفسه تلقائياً خلال دقائق من كل رفعة. الشيء الوحيد المطلوب منك: خطوة واحدة بقاعدة البيانات (Supabase) لأنها تحتاج حسابك أنت.

---

## ثانياً: كود قاعدة البيانات المطلوب تشغيله الآن

### إذا هذه أول مرة تفعّل فيها الميزة إطلاقاً:

افتح هذا الرابط وسجّل دخول بحساب Supabase تبعك:

```
https://supabase.com/dashboard/project/gbmwrvnmvobvieembxmf/sql/new
```

وشغّل **كل** محتوى ملف `supabase/migrations/20260706173035_rbac_staff.sql` (انسخه كاملاً والصقه واضغط Run).

### إذا سبق وشغّلت كود هذا الدليل قبل هذا التحديث:

يكفي تشغيل هذا الجزء الإضافي فقط (نفس الرابط أعلاه، الصقه بصندوق جديد واضغط Run):

```sql
ALTER TABLE restaurant_staff
  ALTER COLUMN pin_hash DROP NOT NULL;

ALTER TABLE restaurant_staff
  ADD COLUMN IF NOT EXISTS code TEXT;

CREATE UNIQUE INDEX IF NOT EXISTS idx_staff_code_unique
  ON restaurant_staff (LOWER(code)) WHERE code IS NOT NULL;
```

إذا ظهرت رسالة خضراء "Success" — تم، خلصت هذه الخطوة نهائياً.

⚠️ إذا كان عندك كاشير أضفته سابقاً بنظام الـ PIN القديم، لازم تحذفه وتضيفه من جديد بالنظام الجديد (خطوة رابعاً بالأسفل) — النظام القديم (PIN) لم يعد يعمل للدخول.

## ثالثاً: كيف تضيف كاشير جديد (من الموقع نفسه)

1. سجّل دخول لداشبورد المطعم كالعادة (**لم يتغيّر شيء بدخولك أنت**).
2. اذهب إلى **الإعدادات ← الموظفين**.
3. اضغط زر **+**:
   - اكتب اسم الموظف.
   - اختر دوره: **كاشير** (أو **مدير** لصلاحيات أوسع).
   - سيظهر لك تلقائياً **كود من 6 أرقام** (لا تكتبه أنت، النظام يولّده وحده).
   - اكتب **كلمة مرور** له (4 أحرف/أرقام على الأقل).
4. اضغط **إضافة**.
5. تظهر لك بطاقة فيها **الكود** و**كلمة المرور** — **صوّرها أو انسخها فوراً** وأعطها للموظف، لأنها بيانات دخوله الوحيدة. (تقدر تشوف الكود لاحقاً من نفس صفحة الموظفين، لكن كلمة المرور لا تُعرض مرة ثانية — لو نسيتها استخدم زر "إعادة تعيين كلمة المرور").

---

## رابعاً: كيف يدخل الكاشير

1. الموظف يفتح رابط الموقع نفسه ويروح لصفحة **تسجيل الدخول**.
2. يضغط تبويب **"الدخول كموظف"** (بجانب "الدخول كمالك").
3. يكتب **الكود** (6 أرقام) و**كلمة المرور** اللي أعطيته إياها.
4. يدخل مباشرة — يشوف: الطلبات، المنيو، السائقين، المخزون (تسجيل الهدر فقط بدون تكلفة الشراء)، وإعدادات المطعم العامة.
5. **لا يشوف إطلاقاً**: الإحصائيات والأرباح، إدارة الموظفين، سجل التدقيق، ولا كلمة مرور حسابك أنت.

وأنت (المالك) تدخل بنفس طريقتك القديمة تماماً من تبويب **"الدخول كمالك"** — بدون أي تغيير.

## خلاصة سريعة

| # | الخطوة | من يسويها | الوقت |
|---|---|---|---|
| 1 | تشغيل كود قاعدة البيانات (قسم "ثانياً" أعلاه) | أنت، مرة واحدة | 3 دقائق |
| 2 | إضافة كاشير من الإعدادات + حفظ الكود وكلمة المرور | أنت | دقيقة واحدة لكل موظف |
